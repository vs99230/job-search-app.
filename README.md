# Job Search Web App

A modern **Job & Internship search web application** built with **React, Vite, TailwindCSS**, and **RapidAPI**.

---

## Features

- Browse jobs & internships from API
- Save jobs for later
- Apply directly via links
- Dashboard with user profile
- Upload resume & track applications
- Responsive design with animations
- Fully client-side, no backend required

---

## Tech Stack

- React (Vite)
- Tailwind CSS
- RapidAPI (Job search API)
- LocalStorage (for storing user data, saved jobs, applied jobs)
